## 2024-03-03 - [MessageList useEffect unmounts]
**Learning:** `computeMessagesFromPath` returns a new array reference every time it is called. Since `MessageList` was using this result as a dependency in a `useEffect` that bound/unbound the `scroll` event listener, the listener was being unnecessarily detached and reattached on every component render (or whenever a new message chunk streamed in, triggering a re-render). In addition, checking scroll position inside an effect that depends on the state it sets (`isAtBottom`) is a clear anti-pattern and can cause unneeded updates.
**Action:** Always wrap `computeMessagesFromPath` (and similar helper functions that map/filter arrays) in `useMemo` if they are passed as props or used as effect dependencies. Separate purely declarative event listener setup (`useEffect` with `[]` deps) from effects that synchronize state with external data changes (`useEffect` with `[messages]` deps).
